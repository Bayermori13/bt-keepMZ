# Bluetooth StayAlive - Anti-Disconnect & Silent Streamer
## جلوگیری از قطع خودکار هندزفری بلوتوث بعد از پایان تماس و آهنگ

این پروژه برای حل مشکل متداول هندزفری‌های بلوتوث ساخته شده است: زمانی که تماس تلفنی قطع می‌شود یا پخش آهنگ متوقف می‌شود، هندزفری به دلیل مصرف بهینه‌ی باتری (Sleep Timeout) به سرعت ارتباط بلوتوث را قطع می‌کند. اما زمانی که صدایی در حال پخش است، هرگز قطع نمی‌شود!

**راه‌حل این برنامه:**
1. یک سرویس پس‌زمینه (Foreground Service) با مصرف باتری بسیار ناچیز راه‌اندازی می‌کند.
2. صدای سکوت کامل دیجیتال (PCM 0) یا فرکانس غیرقابل شنیدن نامحسوس (15 هرتز) ارسال می‌کند تا تراشه صوتی DAC و کانال بلوتوث A2DP بیدار بمانند.
3. **مدیریت هوشمند Audio Focus (بدون کوچکترین اختلال):**
   - هر زمان تماسی برقرار شود یا در اسپاتیفای و موزیک‌پلیر آهنگی پخش کنید، برنامه سکوت را کاملاً متوقف می‌کند تا آهنگ یا تماس با کیفیت ۱۰۰٪ پخش شود.
   - به محض قطع تماس یا پاز شدن موزیک، پخش سکوت در کسری از ثانیه دوباره فعال می‌شود تا هندزفری به خواب نرود!

### چطور برنامه را در گیت‌هاب قرار دهید و فایل APK را دانلود کنید؟

۱. در حساب گیت‌هاب خود یک ریپازیتوری جدید (مثلاً با نام `bluetooth-stayalive`) بسازید.
۲. این فایل‌ها را داخل ریپازیتوری پوش (Push) کنید:
```bash
git init
git add .
git commit -m "Initial commit for Bluetooth StayAlive"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/bluetooth-stayalive.git
git push -u origin main
```
۳. به محض پوش شدن، بخش **Actions** گیت‌هاب فعال شده و گردش کار `.github/workflows/build-apk.yml` به صورت خودکار فایل APK اندروید را بیلد می‌کند (حدود ۱ تا ۲ دقیقه).
۴. در بخش **Actions > Build Android APK > Artifacts**، فایل `BluetoothStayAlive-Debug-APK` را با یک کلیک دانلود کنید و روی گوشی اندروید خود نصب نمایید!
